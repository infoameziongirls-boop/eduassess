How it works
  1. Each student gets a random password. Their username is their student number.
  2. The sheet is shown once. Print it before leaving the page, and do not refresh it.
  3. Cut the slips and hand one to each student, in person.
  4. At first sign-in the student must choose a new password.
Passwords cannot be shown again. If a slip is lost, issue a new one from the student's profile or use "New + slips not yet used".
